# Iz Homework

Permanent React homework platform. Dated, idempotent lesson packages live under `public/homeworks/`; the newest-first index is generated during the build.

## Exercise authoring standard

Every new learner-facing exercise — grammar, vocabulary, practice, reading, listening, matching, gap-fill, dialogue, simulation, and assessment — must use a plausible daily-life, study, or work context. Give enough detail for one defensible answer and use realistic distractors. Do not ask learners to name, explain, or identify a grammar rule in the question. Let them meet the language naturally in a message, conversation, note, plan, or practical choice. For a grammar question, show a short, plain-English explanation after a correct answer that explains why it works in that context; it may name the rule there. Avoid abstract true/false statements: base them on a clear, natural situation or replace them with a contextual choice.
